# Changelog

## 0.1.0

Initial experimental release: SQLite BM25 and Python structural evidence; optional
pinned local BGE/ONNX embeddings, int8 vectors and a persistent cost/frequency-aware
cache quota; heuristic/learned policy experiments; byte-budgeted source context;
content-hash incremental freshness; CLI, Python API, stdio MCP and local inspector.

Includes reproducible small-suite and external comparisons, one public ContextBench
diagnostic, original editable branding and an authentic screenshot launch montage.
See the benchmark and architecture documentation for important limits. No claim of
universal speed, storage or retrieval superiority.
